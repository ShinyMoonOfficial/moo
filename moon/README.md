# 🌙 MoonManager

Менеджер групп Telegram для MoonChat. Python 3.11+, SQLite и стандартная библиотека. У каждого чата свои настройки, предупреждения, статистика и очередь жалоб.

## Запуск на Pterodactyl

1. Создайте **отдельного бота** MoonManager у [@BotFather](https://t.me/BotFather) командой `/newbot`. Если MoonMafia и MoonManager будут работать одновременно, каждому нужен свой токен и отдельный процесс. В Pterodactyl для MoonManager используйте отдельный сервер или выделенный экземпляр Python.
2. Откройте **Files** в корне сервера, где путь заканчивается на `/home/container`. Загрузите `MoonManager.zip` и распакуйте его там. `main.py` должен быть виден в корне рядом с папкой `moonmanager`.
3. В **Files → Новый файл** создайте `.env` **рядом с `main.py`**. Добавьте строку `BOT_TOKEN=` и вставьте после неё токен MoonManager.
4. В **Startup → APP PY FILE** укажите `main.py`. Нажмите **Start**. В консоли появится строка `MoonManager запущен · @имя_бота`.
5. Добавьте бота в MoonChat как администратора. Выдайте права **Удаление сообщений** для фильтров и **Блокировка пользователей** для мута, бана и кика. Отправьте `/check` в группе от своего профиля, чтобы увидеть, какие права Telegram выдал боту.

Дополнительные пакеты, порт и отдельная база данных не нужны. Мут, бан и кик через MoonManager рассчитаны на супергруппы. Администраторы Telegram получают обычные сообщения группы, поэтому для наблюдения за чатом достаточно административных прав. [Telegram Bots FAQ](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get) · [Bot API](https://core.telegram.org/bots/api#restrictchatmember)

## Запуск из репозитория GitHub

1. Распакуйте архив. В корень репозитория добавьте его содержимое, чтобы `server.py`, `main.py` и папка `moonmanager` лежали рядом.
2. Подключите репозиторий к хостингу. Если хостинг запускает `python /app/server.py`, файл из архива использует эту команду. Если указываете команду вручную, используйте `python -u server.py`.
3. В переменных окружения самого хостинга задайте `BOT_TOKEN`. Локальный файл `.env` и папку `data` держите вне репозитория.
4. Если хостинг предлагает тип процесса **Worker** или **Background Service**, выберите его. MoonManager получает обновления Telegram через длинный опрос и запускается как фоновый процесс.
5. Если у хостинга файловая система пересоздаётся при развёртывании, подключите постоянный диск и направьте `MOONMANAGER_DB` на файл базы на этом диске.

После развёртывания найдите в логах `MoonManager запущен` и отправьте в своей группе `/check`. При переносе с другого хостинга остановите прежний экземпляр MoonManager перед запуском с тем же токеном.

## Запуск на Bothost

Укажите `main.py` в поле **Дополнительные настройки → Главный файл (точка входа)**. Оставьте выключенной опцию веб-интерфейса и webhook, потому что MoonManager получает обновления Telegram длинным опросом. Проверьте, что код лежит в корне выбранной ветки GitHub, и выполните новый деплой. Токен введите в поле **Bot Token** в Bothost. [Настройка точки входа](https://bothost.ru/docs/main-file-entrypoint)

Если шаблон Bothost продолжает генерировать запуск через веб-заглушку, добавьте `Dockerfile` из архива в корень репозитория и в **Дополнительных настройках** выберите **Использовать собственный Dockerfile**. Задеплойте проект снова. Этот Dockerfile кладёт код в `/opt/moonmanager` и запускает `main.py` оттуда. База сохраняется в `/app/data/moonmanager.sqlite3`. [Dockerfile на Bothost](https://bothost.ru/docs/custom-dockerfile) · [Постоянное хранилище](https://bothost.ru/docs/database-storage)

## Запуск в PyCharm

Распакуйте архив в отдельную папку, откройте её в PyCharm, создайте `.env` рядом с `main.py` и добавьте токен. Щёлкните по `main.py` правой кнопкой и выберите **Run 'main'**. В терминале из папки проекта можно запустить `py -3 -u main.py` на Windows или `python3 -u main.py` на Linux.

## Команды участников

| Команда | Действие |
| --- | --- |
| `/help`, `/rules` | Справка и правила группы |
| `/profile`, `/id` | Свой профиль и Telegram ID. Ответом на сообщение можно посмотреть данные участника |
| `/top`, `/top rep` | Десятка по сообщениям или по репутации |
| `/rep` или `+реп` | Добавить +1 к чужой репутации ответом на сообщение |
| `/report причина` | Отправить жалобу ответом на сообщение |
| `/warns` | Число активных предупреждений, своё или по ответу |
| `/modhelp` | Команды модерации |

Репутация ограничена пятью плюсами за 24 часа, по одному каждому участнику. Жалобу можно подавать раз в минуту, каждое сообщение можно отметить один раз. Профиль учитывает обычные сообщения, которые бот получил после подключения.

## Команды администраторов

Выполняйте команды от своего Telegram-профиля. MoonManager сверяет действующие права в группе. Команды санкций принимают ответ на сообщение или числовой Telegram ID после команды. Для `/delete` нужен ответ на сообщение.

| Команда | Действие |
| --- | --- |
| `/warn флуд` · `/unwarn` | Выдать предупреждение или снять последнее активное |
| `/mute 15m флуд` · `/unmute` | Выдать временный мут или снять действующий мут MoonManager |
| `/ban 2h спам` · `/ban forever спам` | Временный или бессрочный бан |
| `/unban 123456789` · `/kick причина` | Разбан или исключение с возможностью вернуться |
| `/delete` | Удалить отдельное сообщение |
| `/reports` · `/modlog` | Получить последние жалобы или действия модерации в личку |
| `/resolve 12` | Закрыть жалобу по её номеру |
| `/check` · `/config` | Проверить права бота и посмотреть настройки |

Длительность принимается в минутах (`m`), часах (`h`) и днях (`d`) в диапазоне от минуты до 30 дней. MoonManager работает с ограничениями, которые сам выдал. Для смены ограничений, выставленных вручную, используйте настройки Telegram. Telegram при бане и кике в супергруппе может удалить прежние сообщения участника. [Telegram Bot API](https://core.telegram.org/bots/api#banchatmember)

Запустите бота в личке один раз, чтобы получить `/reports` и `/modlog`. Эти команды отправляются в группе и выдают содержимое в личку только запрашивающему администратору.

## Настройка MoonChat

По умолчанию приветствие, автоудаление сообщений и автомут выключены.

| Команда | Что меняет |
| --- | --- |
| `/setrules Текст правил` | Текст для команды `/rules` |
| `/setwelcome Добро пожаловать, {name}, в {chat}!` | Устанавливает и включает приветствие |
| `/config welcome on` | Включает приветствие с текущим шаблоном |
| `/config flood on` | Удаляет сообщение при седьмом сообщении за 8 секунд или при третьем повторе длинного текста за 25 секунд |
| `/config links on` | Удаляет сообщения с веб-ссылками и скрытыми ссылками |
| `/filter add пример фразы` · `/filter remove пример фразы` | Добавляет и убирает слова и целые фразы из фильтра |
| `/config warnlimit 3` · `/config warnmute 10m` | Включает мут на каждой новой тройке активных предупреждений |
| `/config warnmute 0` | Выключает автомут |

Для приветствия, антифлуда и ссылок используется значение `off`, чтобы выключить настройку. `/setrules off` очищает правила. Автофильтры проверяют также подписи, а ссылки и стоп-слова — ещё и отредактированные сообщения. Администраторы освобождены от автофильтров. Фильтры удаляют подходящее сообщение и записывают причину в журнал. Стоп-слова можно посмотреть командой `/filter`.

## Данные и проверка

База по умолчанию создаётся в `data/moonmanager.sqlite3`. Для другого пути используйте `MOONMANAGER_DB` в `.env`. SQLite хранит настройки, добровольные жалобы, предупреждения, репутацию и счётчики сообщений. Для обычных сообщений полный текст в базе не сохраняется. При переносе проекта остановите бота и перенесите папку `data` целиком.

Чтобы проверить подключение в одиночку, откройте личку с ботом и отправьте `/start`, затем проверьте `/check`, `/setrules` и `/rules` в тестовой группе. Для проверки мута, жалоб и антифлуда нужен обычный участник тестовой группы, поскольку модератор защищён от санкций.

Локальные тесты с имитацией Telegram:

```powershell
py -3 -m unittest discover -s tests -v
```
